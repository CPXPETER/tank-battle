# 坦克大战 Tank Battle 🎮

一个纯 HTML5 Canvas + JavaScript 实现的坦克大战网页游戏，单文件、零依赖，打开即玩。

## 在线试玩

直接用浏览器打开 `index.html` 即可（或部署到 GitHub Pages 后访问）。

## 玩法

消灭一波波来袭的敌军坦克，保卫地图底部的**蓝色能量核心**。

- 核心被摧毁，或生命耗尽 → 游戏失败
- 撑过 **10 波**进攻 → 获胜

## 操作

| 按键 | 功能 |
| --- | --- |
| `WASD` / `方向键` | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |
| `M` | 静音 |
| `回车` | 开始 / 重新开始 |

## 特色

- 🧱 **砖墙**可击破，**钢墙**普通子弹打不穿
- ⚡ **强化弹**（极速射击期间）可以击穿钢墙
- 🎁 击毁敌人有概率掉落道具：护盾 / 极速射击 / 加速 / 额外生命 / 修复核心
- 👾 高波次会出现紫色**精英坦克**（多格血、双发子弹）
- 💥 粒子爆炸特效、屏幕震动、WebAudio 合成音效
- 🏆 最高分本地存档（localStorage）

## 本地运行

无需构建工具，双击 `index.html` 或：

```bash
# 任意静态服务器都可以，例如
npx serve .
```

## 技术

- 原生 HTML5 Canvas 渲染
- WebAudio API 程序化合成音效（无音频文件）
- 单文件，无框架、无依赖
